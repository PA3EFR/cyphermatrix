## Compact Guide

This is a digital safe designed bij the Plusscouts PA3EFR/J Comms Team. The screen asks for a 4-digit code; the numeric code is therefore the main input variable needed to open the safe.

## Possible Input Variables

- Numeric code: A code consisting of exactly 4 digits, entered through the safe interface. This is the direct input that the safe checks.

- Matrix text: The matrix appears to be the source from which you derive the 4 digits. Look for a pattern, sequence, or selection within the matrix that produces exactly four digits.

## On-screen buttons: 

“Reset”, “Pause”, and “Lock” are control buttons, not part of the code itself. Use “Reset” if you want to clear an incorrect entry.

## How to Use It

- Examine the matrix and determine which four digits it points to.

- Enter those four digits into the input field of the safe.

- Check that the order is correct; for a 4-digit code, the sequence is usually important.

- Confirm the entry. If the code is incorrect, use Reset and try another interpretation of the matrix.

## Important Note

The available information explicitly mentions a 4-digit code, but does not yet include the matrix itself or the rules for extracting digits from it. The matrix text is therefore where you should look for the input; the numeric code is the result that you enter.
